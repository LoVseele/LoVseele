# 小学四则运算题目生成器（结对项目）

自动生成小学四则运算题目的命令行程序 + 网页图形界面，支持答案自动批改。

**运行环境：Python 3.8 及以上，不需要安装任何第三方库**（后端只用标准库，前端只用原生 HTML/CSS/JS，零 CDN 依赖）。

---

## 1. 快速开始

### 1.1 命令行（对应需求 3 / 4 / 8 / 9）

```bash
# 生成 10 道 10 以内的四则运算题，写入当前目录的 Exercises.txt 与 Answers.txt
python myapp.py -n 10 -r 10

# 生成 10000 道 100 以内的题目（需求 8：支持一万道题目）
python myapp.py -n 10000 -r 100

# 缺少 -r 时会报错并打印完整帮助信息（需求 4）
python myapp.py -n 10

# 批改题目与答案，统计对错并写入 Grade.txt（需求 9，附加分）
python myapp.py -e Exercises.txt -a Answers.txt
```

Windows 下把 `myapp.py` 改名为 `Myapp.exe` 后，`Myapp.exe -n 10` 与 `python myapp.py -n 10` 等价。

### 1.2 网页界面（需求 1：图形界面）

```bash
python server.py            # 启动后访问 http://127.0.0.1:8000/
python server.py --port 9000 --open   # 指定端口并自动打开浏览器
```

界面只有两个面板：

| 面板 | 功能 |
| --- | --- |
| 出题 | 设置题目数量、数值范围、运算符个数上限，一键生成；展示题目、运算符分布图、答案类型分布图，并写入文件 |
| 批改 | 粘贴或导入题目与答案文本，一键批改，展示 `Correct / Wrong` 统计、题号列表、错题明细，并写入 `Grade.txt` |

出题面板的题目列表下方可以直接逐题填写答案，点「批改作答」即时判定；点「显示答案」查看标准答案。

**演示用地址参数**（省去手动点击）：

```bash
# 打开即自动生成 20 道 10 以内的题目
http://127.0.0.1:8000/?n=20&r=10&auto=1

# 再自动跳到批改面板，并走完「填入题目与答案 → 开始批改」
http://127.0.0.1:8000/?n=20&r=10&auto=1&tab=grade
```

## 2. 参数说明

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `-n COUNT` | 生成题目的个数 | 10 |
| `-r RANGE` | 题目中数值的范围，生成 RANGE 以内的题目（不含 RANGE）；**生成模式下必须给定** | 无（必填） |
| `-m OPERATORS` | 每道题目允许的最大运算符个数（1~3） | 3 |
| `-e EXERCISE_FILE` | 题目文件路径（批改模式） | 无 |
| `-a ANSWER_FILE` | 答案文件路径（批改模式） | 无 |
| `-o OUTPUT_DIR` | 输出目录 | 当前目录 |
| `-s SEED` | 随机种子，用于复现同一套题目 | 无 |
| `-v` | 显示版本 | — |

---

## 3. 输出文件格式

`Exercises.txt`（题目，每行一道，运算符与等号前后带空格）：

```
1/6 + 1/8 = 
7 × (2 ÷ 8) = 
```

`Answers.txt`（答案，行号与题目一一对应；真分数写作 `3/5`，带分数写作 `2'3/8`）：

```
7/24
1'3/4
```

`Grade.txt`（批改结果，格式为需求 9 规定的形式）：

```
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

## 6. 关键设计

**约束校验（需求 5）** 采用「自底向上、校验即求值」的一次遍历：`validate_tree()` 递归返回子树的值，
遇到 `e1 - e2` 时要求 `e1 >= e2`，遇到 `e1 ÷ e2` 时要求 `0 < e1 < e2`（结果必为真分数），
任一条件不满足即整棵树作废重来。因为校验通过时的返回值就是答案，全树只需要走一遍。

**题目去重（需求 6）** 基于表达式树的「规范形式」：`+` 与 `×` 满足交换律，因此递归地对两个子树的
规范形式排序后拼接；`-` 与 `÷` 保持左右顺序；**不做结合律展平**。这样：

* `23 + 45` 与 `45 + 23` 规范形式相同 → 判为重复；
* `3 + (2 + 1)` 与 `1 + 2 + 3` 规范形式相同 → 判为重复；
* `1 + 2 + 3` 与 `3 + 2 + 1` 规范形式不同 → 判为不重复（符合需求原文的约定）。

**难度（面向小学）** 题目按题型生成（纯整数题 / 纯分数题），不使用 0 与 1 作无意义的操作数，
答案不超过 r²、分母不超过 100，分数题最多两步且只用常见分母，整体以一步、两步计算为主。

**性能（需求 8）** 生成 10000 道 100 以内的题目约 0.13 秒，全部互不重复。
